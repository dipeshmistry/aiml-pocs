# langchain-masterclass-labs

Exercises from "ChatGPT and LangChain: The Complete Developer's Masterclass"
(Stephen Grider): adding tools (`12-adding`), parsing structured output
(`13-parsing`), securing API keys (`14-securing`), connecting chains
(`15-connecting`), and chaining prompts together (`16-chains`). Each folder is
a standalone Pipenv project.

Set `OPENAI_API_KEY` in your environment before running any `main.py`.
