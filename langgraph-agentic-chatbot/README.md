# langgraph-agentic-chatbot

LangGraph experiments: `main.py`/`custom.py` build a basic graph-based agent,
`basicchatbot/` and `graph.ipynb` walk through the LangGraph basics in
notebook form, `multiaiagent.ipynb` is a multi-agent graph, and
`ollama_cloud.py` wires the graph up to an Ollama-hosted model.
